# LiteFlow 可视化编排器使用指南

> 本文档介绍 RuoYi-Vue-LiteFlow 内置的 **AntV X6 可视化编排器**：如何拖拽画流程、配置逻辑节点、保存发布与试跑调试。  
> 相关文档：[API 文档](API.md) · [项目 README](../README.md)

---

## 一、进入编排器

### 1.1 入口

| 入口 | 路径 | 说明 |
|------|------|------|
| 链路管理 → **编排** | `/liteflow/editor?chainId=xxx` | 最常用 |
| 菜单 / 首页 → **可视化编排** | `/liteflow/editor` | 进入链路选择页，点选后打开 |
| 从模板创建后自动跳转 | 勾选「打开可视化编排」 | 适合新建链路 |
| 执行日志 → **定位失败 / 定位链路** | 带步骤高亮参数跳转 | 失败排查 |
| 菜单（若已配置） | LiteFlow → 链路管理 | 需 `liteflow:editor:view` |

### 1.2 权限说明

| 权限标识 | 能力 |
|----------|------|
| `liteflow:editor:view` | 打开编排页、查看画布 |
| `liteflow:editor:save` | 保存草稿（写入 `el_data` + `graph_json`） |
| `liteflow:chain:edit` | 保存、发布链路 |
| `liteflow:execute` | 编排器内试跑 |
| `liteflow:chain:reload` | 热刷新规则 |
| `liteflow:chain:permission` | 配置链路级执行/编排权限 |

**链路级权限**（可选）：在链路管理 → **更多 → 执行权限** 中为某条链配置「可执行 / 可编排」角色。未配置时仍按上表菜单权限控制；admin 不受链路级限制。

## 二、界面概览

工具栏提供 **自动布局**（按 EL 模型重新排布），画布右下角为 **小地图** 导航。生产环境若开启 `liteflow.readonly.enabled=true`，保存/热刷新等写操作禁用。

```
+------------------------------------------------------------------+
|  chain: orderProcess    [可视化 | EL文本]  [试跑][自动布局][撤销][保存]... |
+----------+-------------------------------------------+-----------+
| 组件/逻辑 |              X6 画布                       | EL 预览   |
|  面板    |         节点 + 连线                        | 节点属性  |
|          |                                           | 试跑结果  |
+----------+-------------------------------------------+-----------+
```

| 区域 | 作用 |
|------|------|
| **顶部工具栏** | 模式切换、试跑、撤销/重做、校验、保存、热刷新 |
| **左侧「组件」** | 按类型分组的 Java 组件，拖拽或点击追加 |
| **左侧「逻辑」** | IF / SWITCH / WHEN / FOR / CATCH 容器，点击追加到末尾 |
| **中间画布** | 可视化编辑；支持缩放（Ctrl+滚轮）、平移（拖动画布空白处） |
| **右侧面板** | EL 实时预览、选中节点属性、试跑步骤结果 |

## 三、可视化模式：添加节点

### 3.1 普通组件（THEN 串行）

1. 在左侧 **组件** Tab 搜索或展开分组（普通 / 布尔 / 选择 / 循环等）
2. **拖拽** 到画布空白处，或 **点击** 组件卡片 → 追加到链路末尾（THEN 最后一个位置）
3. 画布上蓝色矩形为普通组件，按从上到下顺序串行执行

### 3.2 逻辑容器

切换到 **逻辑** Tab，点击卡片即可在链路末尾追加：

| 节点 | 颜色 | 说明 | 默认结构 |
|------|------|------|----------|
| **IF** | 橙 | 条件分支 | 条件组件 + 真分支 + 假分支（各 1 个组件） |
| **SWITCH** | 绿 | 多路选择 | 路由组件 + 多个分支 |
| **WHEN** | 灰 | 并行执行 | 多个并行子节点 |
| **FOR** | 紫 | 次数循环 | 循环组件 + 循环体 |
| **CATCH** | 红 | 异常捕获 | try 区 + fallback（简化 UI） |

> **注意：** IF 下方固定两条分支（真/假），这是 LiteFlow EL 语义，不是 bug。复杂结构（如 `PRE` / `FINALLY`、嵌套 CATCH）建议用 **EL 文本** 模式编辑。

### 3.3 配置逻辑节点

**推荐：选中黄色/绿色逻辑框（IF、SWITCH 等）**，在右侧 **节点属性** 配置：

| 节点类型 | 可配置项 |
|----------|----------|
| IF | 条件（布尔组件）、真分支、假分支 |
| SWITCH | 路由组件、各分支组件（可添加分支） |
| WHEN | 并行子项、超时秒数 `maxWaitSeconds` |
| FOR | 循环组件（次数）、循环体组件 |
| CATCH | try 节点、fallback 节点 |

下拉选项格式为 **`nodeId · 中文名称`**，支持搜索过滤。

**也可：** 选中分支上的蓝色组件 → 右键 **「替换为组件…」**，或 **「粘贴替换」**（先复制其他节点）。

### 3.4 子链路引用（Phase 3）

切换到左侧 **子链路** Tab，可引用另一条 **已发布** 的 chain 作为编排单元（LiteFlow 子流程语义，EL 中直接写 chainId）。

1. 列表展示除当前链以外的已发布链路
2. **点击** 或 **拖拽** 追加到链路末尾
3. 画布上为 **青色** 矩形，标签带 `⛗` 前缀

> 被引用的 chain 须已发布且 EL 有效；保存前仍会走整体 EL 校验。

## 四、画布交互

### 4.1 选中与高亮

- **单击节点**：选中并在右侧显示属性；选中框加粗
- **单击画布空白**：取消选中

### 4.2 右键菜单

在节点上右键：

| 操作 | 说明 |
|------|------|
| 复制 nodeId | 复制组件 ID 到系统剪贴板 |
| 复制 EL 片段 | 复制当前节点对应 EL 子串 |
| 复制节点 / 剪切节点 | 内部剪贴板（可含整棵 IF 子树） |
| 粘贴到后方 | THEN 顶层：插在选中节点之后 |
| 粘贴替换 | 组件叶子：原位替换 |
| 粘贴到链路末尾 | 追加到 THEN 末尾 |
| 复制到链路末尾 | 快速 duplicate |
| 在前/后插入组件… | 对话框选择组件（仅 THEN 顶层） |
| 替换为组件… | 组件节点换绑 nodeId |
| 上移 / 下移 | 调整 THEN 顶层顺序 |
| 删除节点 | 删除（SWITCH/WHEN 至少保留一项） |

在 **画布空白** 右键：可 **粘贴到链路末尾**（剪贴板有内容时）。

### 4.3 键盘快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+C` | 复制节点到内部剪贴板 |
| `Ctrl+X` | 剪切节点 |
| `Ctrl+V` | 粘贴（顶层选中→后方，否则→末尾） |
| `Ctrl+D` | 复制选中节点到链路末尾 |
| `Delete` / `Backspace` | 删除选中节点 |

> 焦点在输入框时不触发快捷键。

### 4.4 撤销 / 重做

工具栏 **撤销 / 重做** 支持画布结构性编辑（增删移节点、改属性触发的模型变更）。

## 五、EL 文本模式

顶部切换 **EL 文本**，可直接编辑 LiteFlow EL 字符串（高级用户）。

| 操作 | 说明 |
|------|------|
| 切到 EL 文本 | 当前画布 EL 自动填入编辑区 |
| 切回可视化 | 调用解析器还原画布；**EL 无法解析时会阻止切换** |
| 保存 | 以 EL 文本为准解析后写入数据库 |

**适用场景：**

- `PRE` / `FINALLY`、复杂 `CATCH/RETRY` 语法（如 Demo4 `resilientNotify`）
- 精细调整 tag / data / bind 字面量
- 从外部复制 EL 粘贴导入

**执行真相：** 运行时以 `lf_chain.el_data` 为准；`graph_json` 仅用于尽量还原布局。

## 六、保存、发布与热刷新

### 6.1 保存（草稿）

点击 **保存** 时依次：

1. 前端模型校验（孤立节点、缺分支等）
2. 调用 `/liteflow/el/validate` 后端 EL 语法校验
3. 写入 `el_data` + `graph_json`，并标记 **草稿**（`draft_flag=1`）

> 草稿 **不会** 触发热刷新，线上仍执行上一次已发布版本。

### 6.2 发布

回到 **链路管理** → 草稿链路点击 **发布**：

- 版本号 +1，写入 `lf_chain_version` 快照
- 触发热刷新，运行时生效
- 记录规则审计

### 6.3 热刷新

编排器 **热刷新** 按钮：重新加载当前链路的 EL 到 LiteFlow 引擎（不改变草稿/发布状态）。一般 **发布** 后会自动刷新；调试时可手动点。

## 七、试跑与步骤高亮

### 7.1 编排器内试跑

1. 点击 **试跑**
2. 填写请求 JSON（可参考 `docs/demo/` 下样例）
3. 执行后：
   - 弹窗显示完整结果
   - 右侧面板显示步骤串
   - 画布 **绿色** 高亮已执行组件；失败时 **红色** 高亮失败节点

### 7.2 从执行日志定位

**执行日志** → 失败记录 → **定位失败**：

- 跳转编排器并带入 `executeStepStr`
- 自动高亮步骤与失败节点（需库表含 `failed_node_id` 字段，全量脚本 [sql/ry-vue.sql](../sql/ry-vue.sql) 已包含）

### 7.3 EL 在线调试（Phase 3）

点击 **EL试跑**，直接执行当前 EL 字符串（`execute2RespWithEL`），**不入库、不依赖已发布链路**。

| 字段 | 说明 |
|------|------|
| EL 表达式 | 默认可视化 EL 或 EL 文本模式内容 |
| 上下文 Class | 可选，与链路 `contextClass` 相同用法 |
| 请求 JSON | 试跑入参 |

适合调试片段 EL、未保存草稿、或 PRE/FINALLY 等可视化未覆盖的语法。详见 [API 文档](API.md) 第四节。

## 八、组件元数据（tag / data / bind）

选中 **普通组件** 节点，右侧可配置：

| 字段 | 对应 EL | 示例 |
|------|---------|------|
| tag | `.tag("xxx")` | 节点别名 |
| data | `.data("key","value")` | 静态数据 |
| bind | `.bind("key")` | 绑定上下文 key |

修改后 EL 预览区同步更新。保存前仍会走 EL 校验。

## 九、推荐练习路径

按难度递增，对应 `docs/demo/` 样例：

| 顺序 | 链路 | 练习要点 |
|------|------|----------|
| 1 | `helloChain` | 拖拽 3 个普通组件、保存、发布、试跑 |
| 2 | `orderProcess` | 打开已有链，观察 IF + SWITCH 还原，改分支组件 |
| 3 | `parallelAudit` | WHEN 并行 + IF 组合 |
| 4 | `batchProcess` | FOR 循环节点与循环体 |
| 5 | `dynamicPricing` | 脚本组件 + 普通组件串联 |
| 6 | `resilientNotify` | EL 文本查看 CATCH/RETRY，试跑失败分支 |

**从模板创建：** 链路管理 → **从模板创建** → 选择模板 → 可勾选自动打开编排器。

## 十、常见问题

### Q1：IF 下面为什么总是两个节点？

IF 在 LiteFlow 中固定为 **真分支 + 假分支**。请选中 **IF 黄框**（不是下方蓝组件）在右侧改分支；或右键蓝组件 **替换为组件**。

### Q2：保存提示 EL 校验失败？

- 检查 SWITCH 是否至少 2 个分支、WHEN 是否至少 2 个并行项
- 条件组件类型是否匹配（IF 用布尔、SWITCH 用选择组件）
- 切到 EL 文本查看具体语法，对照 [LiteFlow 官方 EL 文档](https://liteflow.cc/)

### Q3：可视化 ↔ EL 切换后画布空白？

EL 解析失败或为空。切回 EL 文本修正语法；或从链路管理重新进入。确保 EL 以 `THEN(...)` 等可解析结构开头。

### Q4：试跑提示链路未启用或草稿？

仅 **已发布**（非草稿）且 **启用** 的链路可执行。请先在链路管理 **发布**。

### Q5：保存成功但执行还是旧逻辑？

保存只是草稿。需 **发布** 后才会热刷新生效。

### Q6：没有某组件？

组件来自 Spring 扫描 `@LiteflowComponent`。新增 Java 组件后重启后端，左侧列表自动更新。

### Q7：提示无权编排 / 无权执行？

检查菜单权限；若配置了 **链路级权限**，确认当前角色已勾选「可编排」或「可执行」。

## 十一、数据存储说明

| 字段 | 用途 |
|------|------|
| `lf_chain.el_data` | **执行权威来源**，LiteFlow 引擎加载此 EL |
| `lf_chain.graph_json` | 画布快照（`lfFlowModel` + X6 cells），便于还原布局 |
| `lf_chain.draft_flag` | `1` 草稿 / `0` 已发布 |
| `lf_chain_version` | 每次发布的历史快照，可回滚为草稿 |

编排器依赖的后端接口详见 [API.md](API.md)，常用：

## 十三、已知限制（v1.0+）

| 项 | 说明 | 变通 |
|----|------|------|
| PRE / FINALLY | 无独立可视化节点 | EL 文本模式 |
| 子链路引用 | 仅支持引用已发布 chain，无可视化展开 | 左栏「子链路」Tab |
| 小地图 / 自动布局 | 未支持 | 手动拖动画布 |
| CATCH/RETRY 细节 | 简化 UI | Demo4 参考 EL 原文 |
| 版本 EL diff | 版本历史页 **对比当前**（行级高亮） | 一键回滚仍走发布流程 |
